Privacy Policy

gcal-bridge · last updated 18 October 2026

Summary

gcal-bridge runs entirely on the owner's own computer. It sends no data to the developer or to any third party. The only external service it talks to is Google's APIs, using the owner's own authorization.

What data is accessed

  • Google Calendar — event titles, times, locations, and links, for the calendars the owner selects.
  • Google Tasks — task titles, due dates, notes, and completion status.

How data is stored

  • The OAuth client_secret.json and the resulting refresh/access token are stored locally at ~/.config/gcal-bridge/ with file mode 0600, readable only by the owner's user account.
  • Calendar and task data is held in memory only for as long as it takes to draw the desktop widget. There is no database, no log of event or task contents, and no cache of personal data on disk.

What is never done

  • No data is transmitted to the developer, to advertisers, or to any analytics service.
  • No data is sold, shared, or used for advertising or profiling.
  • No data is used to train machine-learning models.
  • Nothing is collected from anyone other than the owner of the authorizing account.

Retention and deletion

Because the only stored item is a local OAuth token, deletion is immediate and entirely under the owner's control:

  • Delete ~/.config/gcal-bridge/token.json to remove the stored token, or run gcb auth again to replace it.
  • Revoke the app's access at myaccount.google.com/permissions.

Google API Services User Data Policy

gcal-bridge's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Data is used solely to display the owner's own calendar and tasks on the owner's own device, and for nothing else.

Children

The tool is a personal utility and is not directed at children.
