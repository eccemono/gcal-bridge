gcal-bridge

A personal bridge between a Linux desktop and Google Calendar & Tasks.

What it is

gcal-bridge is a small, self-hosted command-line tool plus a desktop-shell widget. It runs on the owner's own computer, reads the owner's own Google Calendar and Google Tasks, and displays them in the owner's own desktop bar. It also lets the owner add and complete tasks and create calendar events from the desktop.

Who uses it

One person: the owner of the Google account that authorizes it. It is not offered as a service to the public, has no sign-up, no user accounts, and no multi-user support. There is no server component and no third-party hosting.

How it is used

  • The tool requests access to Google Calendar and Google Tasks for the authorizing account.
  • It calls the Google Calendar API and Google Tasks API directly, from the owner's machine.
  • Nothing is sent anywhere else: there is no analytics, no telemetry, and no remote backend.
